# Real-Time Vehicle Tracking and Counting System using YOLOv8

A computer vision application built with Python to detect, track, and count vehicles in traffic videos. 

## Features
- **Multi-Class Tracking:** Independently counts Cars, Trucks, Buses, and Motorcycles.
- **Hardware Acceleration:** Native support for Apple Silicon Mac GPU (`mps`).
- **Telemetry Vector Boundary:** Utilizes a precise line-crossing telemetry checkpoint near the bottom of the video to avoid skipping fast objects.
